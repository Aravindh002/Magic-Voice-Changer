# Magic Voice Changer - Real-Time VoIP Calling App

A modern Android application for making VoIP calls with real-time voice effects.

## Features
- ✨ Real-time voice processing
- 📞 WebRTC-based VoIP calling
- 🎭 Multiple voice effects (Female, Male, Kid, Robot, etc.)
- 🎨 Material Design 3 UI
- 🔒 Firebase backend integration

## Requirements
- Android Studio Hedgehog or later
- JDK 17
- Android SDK 34
- Minimum SDK 26

## Setup
1. Open project in Android Studio
2. Add `google-services.json` to `app/` directory
3. Sync Gradle
4. Run on device or emulator

## Build
```bash
./gradlew assembleDebug
```

## Permissions
- RECORD_AUDIO
- INTERNET
- MODIFY_AUDIO_SETTINGS
